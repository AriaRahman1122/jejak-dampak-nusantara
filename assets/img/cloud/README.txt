JDN Cloud Assets - Soft Edge Version

Versi ini dibuat dengan:
- canvas transparan lebih besar
- cloud tidak di-crop terlalu mepet
- alpha fade ke semua sisi gambar
- cocok untuk animasi scale/opacity agar tidak terlihat potongan kotak

Letakkan folder cloud-soft ke:
  /assets/img/cloud/

Contoh:
  <img class="cloud-img cloud-img-1" src="/assets/img/cloud/cloud-1.png" alt="">
atau gunakan .webp untuk file lebih ringan.
